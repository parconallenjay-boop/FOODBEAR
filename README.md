# FoodBear

A fast-food delivery app built with Flutter for the Philippines. Browse a
sample menu with prices in Philippine pesos (₱), search and filter dishes, save
favorites, add items to your bag, adjust quantities, and place a demo order.

## Run

```sh
flutter pub get
flutter run
```

The supplied bear artwork is used as the in-app logo and launcher icon across
Android, iOS, web, Windows, and macOS. Menu photos load from Unsplash; emoji
placeholders are shown if an image cannot be loaded. Orders and profile details
are local demo data and are not sent to a delivery service.

## Test

```sh
flutter analyze
flutter test
```
